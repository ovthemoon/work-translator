- **감정이 섞인 문장을 담백하게 푼다.** "왜 이렇게 오래 걸려요? 복사 붙여넣기 아닌가요?", "왜 이렇게 사람이 많이 필요해요?"를 비하 없이 설명 요청으로 바꿨다. 비하 표현 자동 점검 0건.

- **판교어와 공공기관 문서는 거의 완벽하다.** 16건 모두 뜻이 정확하고 숫자(6개월, 3년, 7일)를 그대로 옮겼다. 공공 문서는 되물을 질문을 거의 만들지 않아 과잉 질문이 없었다.

## 결함

1. **되물을 질문의 방향이 뒤집힘 (가장 큰 문제).** 보낸 사람이 개발자일 때, 받는 사람이 개발자에게 물을 질문이 아니라 개발자가 받는 사람에게 묻는 질문이 나오는 경우가 있었다. 29건 중 6건.
   - 개발자→클라이언트 "그건 스코프 밖이에요" → 질문: "그 내용이 들어 있다고 생각하신 이유가 있을까요?" (개발자의 질문. 클라이언트는 "추가하면 비용·일정이 어떻게 되나요?"를 물어야 함)
   - 개발자→마케터 "트래킹 스크립트 때문에 느려져요" → "꼭 필요한 것만 남겨도 될까요?" (개발자의 질문)
   - 개발자→기획자 "명세에 예외 처리가 없어요" → "예외마다 무엇을 보여줄지 정해 주실 수 있나요?" (개발자의 질문)
2. **말투의 1인칭이 보낸 사람 쪽으로 새어 나옴.** 개발자→클라이언트 "서드파티 장애"의 주의 문구가 "저희가 대신 안내하거나…"로 개발자 입장에서 쓰였다. 받는 사람이 읽는 글이므로 어색하다. 2건.
3. **원문에 없는 예시 숫자.** "인프라 비용 40% 증가"를 설명하며 "지난달 10만 원이면 이번 달 14만 원"을 지어냈다. 계산상 맞지만 규칙 위반. 1건.
4. **원문 주장을 반박함.** 개발자→디자이너 "그라데이션은 CSS로 하면 성능이 안 나와요"에 주의 문구로 "CSS 그라데이션이 항상 느린 건 아니에요"를 덧붙였다. 번역기가 판정을 내리는 셈이라 부적절. 1건.
5. **응답 시간 꼬리가 김.** 중앙값은 2초인데 6건이 11초 이상, 1건은 27초. 특정 문구 유형과 무관하게 무작위로 발생해 OpenRouter 경유 지연으로 추정. 화면에서는 "번역하는 중…"만 보여서 20초 넘게 기다리면 이탈 가능.
6. **사소한 것.** "인바이트 드릴게요" → "초대장을 보내 드릴게요"(회의 초대인데 초대장 느낌), 반대로 보내기에서 한 메시지 안에 "~습니다"와 "~어요"가 섞이는 경우 3건, 반대로 보내기의 요청 분리 칸에 "작업명을 정하세요" 같은 글쓴이 할 일이 섞인 경우 1건.

## 적용한 수정과 재실행

프롬프트(`prompts/translate.system.md`)에 세 가지를 추가하고, few-shot 예시에 개발자→클라이언트 "그건 스코프 밖이에요"(받는 사람 질문이 올바른 예)를 넣었다.

- 질문은 반드시 받는 사람이 보낸 사람에게 묻는 것. 보낸 사람이 물을 법한 질문 금지 (직군 이름을 자리표시자로 넣어 매번 명시)
- 번역과 주의는 받는 사람이 읽는 글이므로 보낸 사람의 1인칭("저희가") 금지
- 원문 주장을 반박·평가하지 말 것. 비유용이라도 원문에 없는 숫자 금지

## 남은 과제와 제안

1. **질문 방향 3건.** 규칙만으로는 완전히 잡히지 않는다. 개발자가 보낸 사람인 few-shot 예시를 2개 더 넣거나(기획자·마케터 수신), 출력 스키마에 질문마다 "누가 묻는가" 필드를 두고 후처리로 걸러내는 방법이 있다. 후자가 확실하다.
2. **긴 응답 시간.** 화면에 5초 넘으면 "조금 더 걸리고 있어요" 안내를 띄우고, 서버 타임아웃을 30초에서 20초로 줄여 재시도하는 편이 낫다. Upstage 직접 호출과 OpenRouter 경유의 지연 분포를 같은 세트로 비교해 볼 가치가 있다(`npm run eval -- --set eval/phrases.json` 으로 가능).
3. **주의 문구 과잉 여부.** 클라이언트→개발자 16건 전부에 주의가 붙었다. 대부분 유용하지만 "검색이 안 돼요" 같은 단순 버그 제보에까지 붙는 건 과할 수 있다. 사용자 피드백(👍/👎)이 쌓이면 판단.
4. **반대로 보내기 말투 통일.** 한 메시지 안에서 "~습니다/~어요"가 섞이지 않게 규칙에 "한 가지 어미로 통일" 추가.
